# External test on TCGA-BRCA — protocol

Write this down **before** running the model on the TCGA crops, and don't change it after.
Commit this file with the date before the first run.

## Purpose

Check how Sepia, trained only on BACH, behaves on breast tissue from other hospitals,
scanners and stains, including real frozen sections. This is a test of the model **exactly as
built**: no retraining, no new thresholds, no prompt or setting changes.

## Data

Built by `tcga_extract.py` (default: 25 patients, seed 44, 6 fields of view per slide,
target 0.42 µm/px; set `--target-mpp` to the BACH value in Sepia's inventory).

| Group | Source | Slide-level label |
|---|---|---|
| `ffpe_tumor` | Diagnostic FFPE slide, Primary Tumor | Invasive |
| `frozen_tumor` | Frozen tissue slide, Primary Tumor | Invasive |
| `frozen_normal` | Frozen tissue slide, Solid Tissue Normal | Normal |

The same patients contribute to every group. Fields of view are sampled at random among
tissue-rich regions; no model chooses them.

**Not available from TCGA:** benign and in-situ labels. Four-class accuracy, the in situ vs invasive
distinction, and the p63/calponin rule cannot be tested here.

## How Sepia is run

Each crop goes through Sepia's existing pipeline as a case: tiling, tissue QC, UNI2-h embedding,
the **BACH-trained** linear probe, the BACH temperature, the BACH conformal thresholds, and the
BACH reliability threshold. Output goes to `artifacts/eval/external_tcga.json`, separate from the
BACH results.

## Primary analyses (slide level)

Crops inherit their slide's label, but a tumor slide's crop may show only stroma or fat, so
results are computed **per slide**:

- **Slide invasive score** = the **maximum** calibrated P(invasive) over the slide's crops.
  (The number of crops per slide is fixed at 6 so normals don't get more chances to be flagged.)
- **Slide called invasive** = any crop has Invasive as its top class.

Report, with 95% intervals bootstrapped over patients:

1. **Sensitivity on FFPE tumor slides:** share of `ffpe_tumor` slides called invasive.
2. **Frozen tumor vs frozen normal:** AUROC of the slide invasive score, plus sensitivity and
   specificity at Sepia's own rule. Tumor and normal are both frozen, so preparation is not a
   confound.
3. **FFPE vs frozen tumor:** sensitivity in each. The difference estimates the cost of real
   frozen-section artifacts.

## Secondary analyses

4. **Reliability flag rate** by group, compared with BACH test images (19% clean). Expect higher
   on TCGA; report whether it is.
5. **Out-of-distribution percentile** by group, compared with BACH.
6. **Tier placement:** share of tumor slides with at least one crop in tier 1–2 under Sepia's rule.
7. **Crop-level P(invasive) distributions** per group (histograms), for context only.

## What will be reported regardless of outcome

All of the above, including drops in performance, with the crop counts and any slides that failed
to download or had fewer than 6 tissue-rich fields. A drop on external data is expected and is
reported as a finding, not hidden.

## Limitations to state

- Slide-level labels; no tumor outlines, so some tumor-slide crops contain no tumor.
- No benign or in-situ cases; specificity is measured only against normal tissue.
- Normal slides are adjacent to tumor and may contain changes that aren't strictly normal.
- Small sample (about 25 patients); intervals will be wide.
- Resolution matched via slide metadata; some slides may need an estimated value (flagged in the manifest).
