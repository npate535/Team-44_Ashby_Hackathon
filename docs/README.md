# Sepia documentation

Research prototype, not for clinical use. Start with the [fact sheet](FACT_SHEET.md): it holds the data units, splits, test metrics, every test misread and the external test. Files marked *generated* are written by a script from `artifacts/eval/*.json`; edit the script, not the file.

## Results and evidence

| Document | Contents |
|---|---|
| [FACT_SHEET.md](FACT_SHEET.md) | Data units, splits, test metrics with intervals, confusion matrix, every misread, dataset roles, reference distributions, what is pretrained or trained (generated by `eval/fact_sheet.py`) |
| [RESULTS.md](RESULTS.md) | Every evaluation with 95% patient-grouped intervals (generated by `eval/results_md.py`) |
| [ATTENTION_COMPARISON.md](ATTENTION_COMPARISON.md) | Attention-based MIL vs the production linear probe on identical inputs (generated) |
| [HUMAN_BASELINE.md](HUMAN_BASELINE.md) | Published pathologist reader studies and clinical turnaround benchmarks, with their limits as comparisons |
